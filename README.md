## Overview

WFA Curriculum Planner provides a web-based workspace for schools and education teams managing teaching objectives and academic activities throughout a defined 39-week period.

Educators and curriculum groups can use the planner to inspect and organize long-range academic plans in one place. Since it runs in a modern browser, it offers an accessible way to map out the school year without requiring a dedicated desktop application.

- Map curriculum material across all 39 school weeks.

- Access the planning workspace through a web browser.
- View the academic year as one organized planning timeline.
- Refer to the plan while preparing curriculum materials with a team.
- Structure planning around the practical requirements of an education environment.
